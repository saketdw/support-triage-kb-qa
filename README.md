# Support Triage & KB Question Answering

Take-home practical in two parts:

- **Part A** — review of an inherited support-ticket route classifier (verdict,
  honest evaluation, and a minimal working fix).
- **Part B** — a question-answering service over a *versioned* knowledge base,
  where every answer must be correct **as of** the date the question is asked
  about.

Full write-up, exact run commands, and the evaluation arrive with the final PR.
